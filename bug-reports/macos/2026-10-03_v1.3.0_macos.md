## 1. Faible — `pnpm-workspace.yaml` modifié par un simple `pnpm install`

Avec pnpm 11.7.0, `pnpm install --frozen-lockfile` sans `--config.dangerouslyAllowAllBuilds=true` échoue (`ERR_PNPM_IGNORED_BUILDS: core-js, electron-winstaller, esbuild@0.21.5, esbuild@0.27.7`) et **ajoute** au fichier suivi :

```yaml
allowBuilds:
  core-js: set this to true or false
  electron-winstaller: set this to true or false
  esbuild: set this to true or false
```

Le commentaire du fichier le signale déjà pour la CI. Un contributeur local se retrouve avec un fichier modifié et une install incomplète (esbuild absent). Piste : documenter le flag dans le README / CONTRIBUTING ou renseigner `allowBuilds`.

## 2. Faible — tests `apps/web` en échec avec Node ≥ 25

`pnpm test` sous Node 26.7.0 : `apps/web` **28 échecs / 134** (`src/store/settingsStore.test.ts` 18/18, `src/store/timerStore.test.ts` 10/10) :

```
TypeError: Cannot read properties of undefined (reading 'setItem')
 ❯ Object.setItem node_modules/.pnpm/zustand@5.0.15…/middleware.mjs:300:42
 ❯ src/store/settingsStore.test.ts:8:20
```

**Sous Node 22 (version de la CI), 134/134 OK.** Cause probable : depuis Node 25, `globalThis.localStorage` existe en natif (vide sans `--localstorage-file`) et masque celui de jsdom dans Vitest. `package.json` déclare `"engines": { "node": ">=20.11.0" }`, ce qui autorise Node 25+. Piste : borner `engines`, ou forcer le `localStorage` de jsdom dans le setup de test.

## 3. Faible — enregistrement comme élément d'ouverture refusé

```
ERROR:electron/shell/common/platform_util_mac.mm:221] Unable to set login item: The operation couldn't be completed. Operation not permitted
```

`app.setLoginItemSettings` est refusé par macOS pour une app non signée lancée hors de `/Applications`. Attendu pour un build non signé, mais l'option « ouvrir au démarrage » ne fonctionnera pas en silence. Piste : remonter l'échec à l'UI sur macOS.

## 4. Cosmétique — boutons de fenêtre macOS sur la barre latérale

La fenêtre utilise `titleBarStyle: 'hidden'` (`apps/desktop/src/windows.ts:145`). Sur macOS, les trois boutons natifs sont dessinés en haut à gauche par défaut et tombent sur le coin arrondi de la carte de la barre latérale (vérifié par capture d'écran). Piste macOS uniquement : `trafficLightPosition` ou un retrait en haut de la barre latérale quand `process.platform === 'darwin'`.
